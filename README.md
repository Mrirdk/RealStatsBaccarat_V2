# AutoRobot Baccarat V2 (Android 14 - Kotlin)

Phiên bản nâng cấp tự động bắt kết quả từ màn hình (MediaProjection) kèm Con Robot Mini nổi và Bảng Báo Mini tự động bật ra khi có kết quả mới.

## Xuất file APK nhanh qua GitHub Actions
1. Giải nén `RealStatsBaccarat_V2_AutoRobot.zip`.
2. Tải toàn bộ thư mục bên trong (bao gồm cả thư mục ẩn `.github`) lên kho GitHub của bạn.
3. Vào tab **Actions** trên GitHub, chờ build xong và tải tệp `RealStatsBaccarat-AutoRobot-APK`.
